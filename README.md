A highly immersive, narrative-driven personal portfolio designed to bridge the gap between advanced web engineering and cinematic storytelling. Built with React, Tailwind CSS, and Framer Motion, this portfolio showcases my skills as an **AI Engineer and Full-Stack Developer**.

## ✨ Key Features

*   📱 **100% Mobile Responsive:** Meticulously engineered to look and feel completely native on mobile devices. Features distinct mobile components like a highly-legible bottom glassmorphism navigation bar, touch-friendly tech pill grids, and fluid card stacking.
*   🎥 **Cinematic 3D Scroll Animations:** Utilizes Framer Motion's `useScroll`, `useTransform`, and `useSpring` to create hardware-accelerated, frame-by-frame scroll-linked animations, including a 3D rotating skills wheel and a scroll-stacking project gallery.
*   💎 **Premium Glassmorphism & Matte UI:** Features a custom dark/neon aesthetic (`#0d0d12` & `#18181c` charcoal) layered with deep `backdrop-blur-2xl` glass effects and a dynamic neon accent (`#FACC15` / `#d9ff66`).
*   🎞️ **Tactile Film Grain & Vignette:** A global SVG fractal noise overlay and radial gradient vignette remove the "flat digital" look, giving the entire site a realistic, matte-film texture.
*   📧 **Live Contact Form:** Fully integrated with Formspree for immediate, serverless email transmissions, featuring a custom-styled dropdown and dynamic expanding fields.

## 🛠️ Tech Stack

*   **Framework:** React 18 / Vite
*   **Styling:** Tailwind CSS (v4)
*   **Animation Engine:** Framer Motion
*   **Typography:** 'Anton' (Display) & 'Inter' (Body) via Google Fonts
*   **Deployment:** Vercel

## 📂 Component Architecture

*   `Hero.jsx`: Immersive landing viewport with staggered typography, outline-stroke text, and wave animations.
*   `Navbar.jsx`: Dynamic scroll-spy navigation. Features a collapsing top-bar for desktop and a sticky, heavy-blur bottom-bar for mobile.
*   `ImageTransition.jsx`: Complex 3D transformations (`rotateY`, `rotateZ`) anchored to precise document scroll depths.
*   `Projects.jsx`: A 450vh scroll-stacking gallery with immersive, full-screen details modals and background blurring.
*   `Skills.jsx`: A dual-layout component featuring a 360° mathematically mapped 3D icon wheel for desktop, and an optimized, touch-friendly pill grid for mobile.
*   `Contact.jsx`: Interactive contact section with a physics-based floating button and fully validated submission form.
